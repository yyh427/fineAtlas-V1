# 连接契约和检查范围

分类有效层允许多父节点，通过 ACTIVE `IS_A` 与 ACTIVE `SAME_CONCEPT` 身份组构建，环路检查 PASS。5,866,569 个分类根可达身份组的父组深度与证据一致性检查通过。具体实例、属性、任务类别不参与分类 `IS_A`。

8,741,157 个有效来源 UID 具有分类路径；3,398,389 个实例、属性或任务类别具有独立的类型连接；其余 188,985 个有效来源记录保留用于来源、元数据或待审。两种可达性分开计算，不能把大量地名实例当作新增细粒度类型数量。

原六个数据集 755/755 通过数据集内部 UID/身份组唯一性与分类路径检查。全部 13 个目录的 1,822 个原生 UID 在各自数据集内唯一，1,495 个已审查映射具备路径，327 个原生类别的现实类型映射待审。路径检查与来源范围审查不衡量图像识别准确率，不认证全部继承来源断言。

同名不提供身份凭据。例如 river Acheron 与生物分类 Acheron、湖泊 Balaton 与樱桃栽培品种 Balaton、矿物 malachite 与同名蝶类保留不同 UID 和身份组。仅凭标签唯一性提出的身份桥保留待审；6 个已发现意义冲突的身份桥隔离，组件区分回归通过。

WordNet 的原生实例指针使用 INSTANCE_OF 恢复。命名山峰、河流、历史计算机实物不作为型号或类别的 IS_A 下位。矿物类型采用可包含有机矿物的物质入口，避免强塞入限定无机物的旧词义；微处理器、集成电路和电路板按独立定义接到合适的电路/部件类型。

默认 `neighbors()` 返回分类父子。`instances()` 返回具体实例，`relations()` 返回明确的非分类关系，`path()` 的末步明确标注 INSTANCE_OF、ATTRIBUTE_KIND_OF 或 DEPICTS_TYPE。`view="all"` 允许查看未接通来源，但不把待审边激活。

详见 [VALIDATION.json](../VALIDATION.json)、[CONNECTIVITY.json](../CONNECTIVITY.json) 和 [datasets.csv](datasets.csv)。
