# V34 / v1.1.0 单库历史版本

V34 于 2026-10-03 首次将 V33 的 31 个 SQLite 依赖合并为一个 `fineatlas.sqlite`。该不可变快照保留 8,916,971 个来源 UID，其中 7,955,564 个从 WordNet 根可达（89.2%），961,407 个未接通。六数据集755个目标类别及V33新增59个节点的实际路径均通过。
