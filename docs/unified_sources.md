# 来源与分发范围

本候选固定 WordNet 3.1 和已有专业来源原生标识、定义及关系语义。原数据许可分别适用；接口代码的 MIT 许可不替代第三方数据许可。数据库内的冻结清单及公开附件 `frozen_metadata.json` 记录 SDK、构建脚本和本地全部冻结输入 SHA，完整内部审阅输入不作为公开数据归档。

AviList 使用 v2025b，遵循 CC BY 4.0；OpenTree 使用实际原生版本 OTT 3.7draft3，保留原父声明与放置状态。FAA/EPA 只用明确目录和字段组织已有型号及配置，不将厂商、年份和属性当作分类。

新增 ABO 家具仅四条目录配置身份，保留稳定 domain/item_id、原始元数据、许可和署名，未导入图像或 3D 资产，也不宣称全球型号或物理实例。详情见 [DATA_SOURCES.md](../DATA_SOURCES.md) 与 [生活领域](living_domains_v1.10.1.md)。

原厂和论文核验仅在本地保存必要证据；原始第三方 HTML/PDF/XML 不放入 Git 或公开附件。CUB 历史全名、CRJ 原生层次和 OTT 父级证据只用于支持明确范围的变更，不外推为整来源全面认证。
